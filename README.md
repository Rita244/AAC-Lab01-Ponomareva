## Контрольные вопросы
1.  **Почему программа может узнать имя компьютера, хотя вы не писали его в коде?**
    Программа обращается к операционной системе через специальные библиотеки (API). ОС хранит эти сведения о себе и предоставляет их программе по запросу.
2.  **Какую роль играет операционная система, когда программа запрашивает у неё сведения?**
    ОС выступает посредником. Она управляет ресурсами компьютера и предоставляет программам доступ к системной информации (железо, настройки, переменные среды).
3.  **Что означает «64-битная ОС»?**
    Это означает, что операционная система может обрабатывать данные разрядностью 64 бита за один такт и адресовать более 4 ГБ оперативной памяти.
4.  **Что показывает Environment.ProcessorCount и обязательно ли это число совпадает с числом физических ядер?**
    Показывает количество логических процессоров. Если  на процессоре включена технология Hyper-Threading, одно физическое ядро может представляться системе как два логических, то не обязательно
5.  **Чем память процесса (WorkingSet) отличается от всей оперативной памяти компьютера?**
    WorkingSet — это объем физической памяти (ОЗУ), который в данный момент выделен конкретно для этого процесса. Вся оперативная память — это общий объем ОЗУ, доступный для всех программ и самой ОС.
6.  **Почему одна и та же программа без изменений в коде может показать разные результаты на разных компьютерах?**
   Потому что программа считывает параметры среды, в которой она запущена. Разные компьютеры имеют разное железо (процессоры, память) и разные версии операционных систем.
